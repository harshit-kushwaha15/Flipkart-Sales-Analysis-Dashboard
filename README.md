# Flipkart-Sales-Analysis-Dashboard
Flipkart Sales Analysis Dashboard is a data analytics project focused on analyzing e-commerce sales, revenue, products, categories, customers, and regional performance. Built using Excel, SQL, Python, Pandas, and Power BI, it includes data cleaning, KPI analysis, interactive visualizations, and dashboards for data-driven decision-making.
# 🛒 Flipkart Sales Analysis Dashboard

## 📌 Project Overview

**Flipkart Sales Analysis Dashboard** is a data analytics and business intelligence project developed to analyze e-commerce sales performance. The project transforms raw sales data into meaningful insights related to revenue, products, categories, customers, and regional performance using interactive dashboards.

## 🎯 Objectives

* Analyze overall e-commerce sales performance.
* Track sales and revenue trends.
* Identify top-performing products and categories.
* Analyze regional sales performance.
* Monitor key performance indicators (KPIs).
* Identify customer and purchasing patterns.
* Create interactive dashboards for data-driven decision-making.
